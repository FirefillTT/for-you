# Тебе письмо ✉️

Интерактивное приглашение на первое свидание: лоадер, конверт с сургучом,
ночной город с параллаксом, убегающая кнопка «Нет», календарь, выбор еды и
развлечений, билет на свидание и обратный отсчёт.

**Сайт:** https://firefilltt.github.io/for-you/

## Как это работает

- Сайт — статический, живёт на GitHub Pages.
- Ответы шифруются прямо в браузере (ECDH P-256 + AES-GCM) и улетают в
  [ntfy.sh](https://ntfy.sh) — без регистрации и серверов.
- Страница `mailbox.html` расшифровывает их приватным ключом, который есть
  только в секретной ссылке (после `#k=`; эта часть ссылки никуда не отправляется).
- GitHub Action каждые полчаса переносит зашифрованные ответы в `answers.json`,
  потому что ntfy хранит сообщения только 12 часов.

## Персонализация

Имена можно передать прямо в ссылке:

```
https://firefilltt.github.io/for-you/?to=Маша&from=Саша
```

Тексты, варианты еды и развлечений — в начале `js/app.js`.
